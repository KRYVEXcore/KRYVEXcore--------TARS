# CASE — 20-second demo script

Read this aloud while screen-recording. Timestamps are approximate — let
CASE's actual responses set the pace, don't rush past them.

| Time | Say | Do |
|---|---|---|
| 0:00–0:03 | "This is CASE — a robot assistant that lives in one Python file, zero dependencies." | Show the page: title, orb, slider, feed. |
| 0:03–0:09 | "Ask it anything — it replies dry, deadpan, and says it out loud." | Type a question (e.g. "what's the meaning of life"), hit Enter. Let the reply appear and speak. |
| 0:09–0:14 | "Now watch — I'll hand it a real mission. It runs Claude Code in the background, research allowed, my files untouched." | Type a short brief (e.g. "look up today's top AI headline"), click **SEND CASE — DO THE WORK**. Let the "CASE is on it…" status show. |
| 0:14–0:20 | "And it reports back — full write-up, plus a spoken summary. That's CASE." | Report lands in the feed; let the spoken summary play out. |

## Notes for a clean take

- Have `ANTHROPIC_API_KEY` (and `ANTHROPIC_WORKSPACE_ID` if needed) already
  set before you hit record — no terminal fumbling on camera.
- Click **AUDIO ON** once before you start narrating, off-camera or in the
  first second, so both replies are heard.
- Pick a mission brief you know resolves quickly (a short lookup, not a
  deep research task) so it finishes within the recording.
- If you have a beat to spare, drag the **PERSONALITY** slider once
  between the chat and the mission — it's a strong visual and the spoken
  confirmation fills dead air nicely.
